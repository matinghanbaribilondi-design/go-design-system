## دستورهای تأیید

```bash
npm install                                    # only needed to rebuild the engine
node scripts/build.mjs --assemble-only         # proves code.js matches src/core.js
npm test
node scripts/verify.mjs package tests/fixtures/golden-package
node scripts/verify.mjs ui tests/fixtures/ui-pass --package tests/fixtures/golden-package
node scripts/verify.mjs ui tests/fixtures/ui-fail --package tests/fixtures/golden-package
node tests/zip-roundtrip.test.js
node tests/docs-consistency.test.js
node scripts/benchmark-ai.mjs
```

همهٔ دستورها باید از ریشهٔ `plugin/global-design-system-plugin` اجرا شوند. `node tests/docs-consistency.test.js` اعداد همین سند و مسیرها و کدهای قاعده را با کد تطبیق می‌دهد و اگر چیزی drift کند شکست می‌خورد؛ پس ستون‌های این جدول دستی به‌روز نمی‌شوند بلکه از خروجی همان تست گرفته می‌شوند.

## پذیرش کامل

پذیرش کامل فقط پس از موارد زیر قابل اعلام است:

1. تأیید D7 و پیاده‌سازی Contract فونت/Asset.
2. ارائه و تست Fixture واقعی Figma ناشناس‌شده.
3. تولید Artifactهای سه حالت Benchmark و انجام Human Review.
4. تعیین تکلیف مسیر Component JSON، گزارش Validation نهایی و کدهای Legacy.
